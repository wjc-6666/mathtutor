# MathTutor V1.2.1 候选使用与恢复说明

代码已安装到桌面项目，但验收失败，检索active仍为V1.2。不要把该候选宣称为通过验收的版本。

打开 http://127.0.0.1:8000 → Retrieval Debug 2.1 → 选择“V1.2.1 候选（不切换 active）” → 输入问题检索。各Query Trace阶段均可展开；点击候选相似关系独立查看三类评分。普通学习界面继续使用V1.2。

本地复现（PowerShell，在项目根目录）：

```powershell
.\.venv\Scripts\python.exe -m pytest -q --basetemp=.\data\pytest-temp
.\.venv\Scripts\python.exe -m app.cli search-v121 "向量空间间保加法保数乘的双射叫什么"
```

index-v121只读取现有V1.2 generation创建新候选，不执行OCR、不重新下载模型，不发布active。失败的acceptance.json会被promote-v121拒绝，当前不应尝试人为绕过。

本次代码包仅适用于现有V1.2已安装、现有E5与索引存在的项目，不包含教材、模型、OCR、数据库、聊天记录。无需再次安装依赖。运行中的服务器需要重新启动才会注册新API，本机8000已经完成重启。

恢复稳定V1.2行为：当前已经如此，无需恢复数据。若以后有候选active，可在启动进程的环境中设置RETRIEVAL_VERSION=v12并重启服务；设置v11可使用V1.1.1。不要删除任何generation。

恢复原V1.2界面及代码：V1.2稳定代码备份.zip保存本次开始时的app/main.py、app/cli.py、app/ui/index.html。停止属于该项目的uvicorn进程后，将这三个文件复制回项目对应位置，再正常启动服务。备份不包含任何数据库或数据文件；不要覆盖data和books。新模块不会被原代码引用，可保留。

独立评分协议记录和冻结SHA见验收报告。已经看过的本次holdout，下一轮如用于调参便属于开发资料；必须建立另一套新holdout。
